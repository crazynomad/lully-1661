# Lully 1661 — research sources for demo content

**Status:** demo, not for production
**Compiled:** 2026-05-09
**Purpose:** record the public-source provenance of every piece of content seeded into `content/` so the client can review and approve before launch. Every photo currently in `public/content/` is a placeholder — none are sourced from third-party imagery.

## Why this file exists

The user authorised gathering Lully 1661 brand material from public sources (Google, Instagram, Uber Eats) to build a demo site. We did *not* download any third-party imagery; instead we generated branded placeholder JPGs that say "PLACEHOLDER · DEMO ONLY" so there is no copyright ambiguity. Text content (addresses, hours, brunch items, atmosphere descriptions) was synthesised from the sources below, often paraphrased rather than quoted, with PT/EN versions written by us. **No content here is licensed for production use without client approval.**

## Provenance protocol for future updates

When seeding additional content from public sources:
1. Verify the source page is publicly accessible (no paywall, no login required).
2. Paraphrase rather than quote at length — long verbatim quotes risk copyright issues.
3. Add a row to this file with the URL and date accessed.
4. Mark anything experimental with `# Demo content seeded YYYY-MM-DD.` at the top of the YAML file.
5. Never download third-party photos without explicit licence — generate placeholders instead.
